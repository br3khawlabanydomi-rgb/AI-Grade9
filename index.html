Explanation and examples

A structured AI solution is a workflow of interacting components rather than a single magic step. The core components are the data that is supplied, the prompt or rule that directs the tool, the tool or model that carries out the task, and the output that is evaluated against the defined problem. Designing at this level means specifying each component and, crucially, the interactions between them - what the prompt asks of the data, what shape of output the tool can return, and how the output is checked. Building is not training a model from scratch; it is composing and configuring the components so they interact reliably to solve a defined problem. The design skill being developed is systems thinking: decomposing a defined problem, assigning each part to a component, and reasoning about how a change in one component propagates to the others. Verify before you trust: check the output against the defined problem, then trace back to the component that failed.

Source activity

Hands-on activity guide Overview: Pairs design and build a structured four-component workflow - data, prompt, tool and output - that solves one defined problem, using a card-based simulated AI so no accounts or personal data are needed. Grouping / timing: Pairs for the design and build, whole class for the debrief. Tool: A simulated-AI card deck of pre-generated, non-personal output cards prepared by the teacher stands in for the tool component - account-free, no personal data, and it works even with no devices. If a device is used it is the school-approved tool, teacher-operated on the board only. Facilitation steps: 1. Choose one defined problem from the problem menu, for example turn eight anonymised feedback lines into a labelled priority list. 2. Specify the data component - exactly what data your workflow will be given, with no personal data included. 3. Write the prompt component - the clear instruction that will direct the tool on what to do with the data. 4. Place the tool card that matches your prompt; this is the AI step that carries out the task. 5. Run the workflow and record the structured output, then note one interaction between two components. 6. Evaluate the output against the defined problem and a trusted reference, then tick or fix each component. Unplugged fallback: The whole activity is already unplugged using paper cards. For a fully human version, one student acts as the tool and follows the pair's written prompt exactly, using only the supplied data, while the others evaluate whether the output solves the defined problem.
