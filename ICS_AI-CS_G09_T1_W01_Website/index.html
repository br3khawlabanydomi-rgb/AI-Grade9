  • I can help write our unit success criteria and our safe, responsible-use rules for AI tools.

Explanation and examples

An AI system is not a single black box but a set of interacting components: data (the examples a model learned from or draws on), a model (the trained system that does the processing), and a prompt or input (the instruction that steers it). These components interact to turn an input into an output - change the data, swap the tool, or reword the prompt, and the output shifts. This launch lesson surfaces what students already know about the input-process-output workflow and reframes the process as interacting parts; it does not yet build a workflow. Systems thinking - seeing the parts and their relationships rather than one lump - is the habit this unit develops. Keep all tool use teacher-operated, account-free and free of personal data, and verify every output against a trusted source before trusting it. Anticipated misconceptions Misconception How to address it The AI is just one thing that gives you an answer. Reveal the separate components behind one output - data, tool, prompt - and show that changing any one of them changes the result; the 'AI' is a system of interacting parts. The prompt is the whole AI. Show the same prompt giving different outputs when the data or the tool changes; agree that the prompt is one component that steers the tool, not the system itself. If the AI is confident, the output must be right. Display a curated output that is confidently wrong, check it against a trusted source, and establish verify-before-trust as a class norm.
